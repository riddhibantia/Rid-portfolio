EduReels

Overview

EduReels is an interactive, bite-sized learning platform that aims to deliver educational courses through 60-second micro-videos combined with integrated quizzes. The application helps users learn key technical and non-technical skills quickly during their spare moments.

Technologies Used

React TypeScript Tailwind CSS HTML5 Video API Local Storage

Key Features

  • Auto-advancing 60-second video feeds.
  • Embedded pop-up multiple choice quizzes to test knowledge retention.
  • Local progress tracking dashboard.
  • Responsive layouts for smooth viewing on mobile screens.

Road Accident Prediction

Overview

An intelligence system modeling historical crash data to forecast road risk probabilities. The project trains a Random Forest Classifier to identify high-risk stretches of road based on speed limit, weather forecast parameters, and historic time patterns.

Technologies Used

Python scikit-learn pandas NumPy Jupyter Notebooks

Key Features

  • Interactive prediction dashboard (built with Python web components).
  • Random Forest Classifier model with over 82% hazard detection accuracy.
  • Data preprocessing pipeline adjusting for missing categorical fields.
  • Feature importance charts displaying key hazard indicators.
Repository Live Demo

Employee Attrition Predictor

Overview

An HR dashboard predicting company staff attrition probability. Utilizing survey scores (work-life balance, environment satisfaction) and business metrics (years at company, overtime frequency), the dashboard displays custom risk ratings for departments.

Technologies Used

Python pandas TypeScript Chart.js Logistic Regression

Key Features

  • Interactive department filter with aggregate turnover gauges.
  • Individual employee risk evaluation calculators.
  • Correlation analysis of salary hikes versus attrition.
  • Clean dashboard visualizations showing key parameters.
Repository Live Demo

Research Intelligence Platform

Overview

An semantic search engine for academic PDFs. Utilizing pre-trained Transformer embeddings, the application reads research uploads and automatically maps semantic relations, grouping them visually for researchers.

Technologies Used

TypeScript SQLite HuggingFace Transformers.js Vector Cosine Similarity

Key Features

  • Direct local semantic search capability (search by concept, not keyword).
  • Interactive similarity cluster network representation.
  • Automatic document summary generation using NLP models.
  • Fully local database caching for immediate offline usage.
